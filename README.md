# HKMU_SoftwareEngineering

Food Ordering App (iOS)
A complete food delivery application developed using SwiftUI + Firebase.
-----------------------------------------------------------------------------

Features
User registration/login (Firebase Authentication)

Browse restaurants and menus

Add to cart and checkout

Admin backend: Add/edit/delete restaurants and menus

Order tracking
-----------------------------------------------------------------------------

Technical Architecture
SwiftUI

Firebase Firestore

Firebase Authentication
-----------------------------------------------------------------------------
How to Run:

1.Clone this project

2.Open .xcodeproj or .xcworkspace

3.Run on a simulator or a real device in Xcode
